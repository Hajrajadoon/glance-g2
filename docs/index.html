Careful with your inbox

Glance asks Google for two permissions only: read mail and send mail. It cannot delete, archive or change anything else.

  • No send without a clickVoice can open the confirm screen. Only a click on the glasses sends.
  • The glasses never choose who gets the replyThe server takes the address from the stored email. No-reply addresses are refused, and each reply can be sent only once.
  • No invented detailsIf a draft adds a name or number that is not in the email, or ignores what you asked, it is thrown away and replaced by a safe reply.
  • Emails are treated as untrusted textInstructions hidden inside an email are ignored by the AI.
  • Nothing is storedEmails are never written to disk. Sign-in tokens live in server memory. API keys stay on the server and never ship inside the app.

Questions

Do I need Even G2 glasses to try it?

No. Glance runs in the free Even Hub simulator, and the demo above shows the same screens. It has not been tested on physical glasses yet.

Does Glance send emails by itself?

No. Every reply needs your final click. In demo mode nothing is sent at all.

Is my email stored anywhere?

No. Glance reads your unread mail when it starts, keeps it in memory while the server runs and never writes it to disk. Sign-in tokens are also held in memory only.

Which AI writes the drafts?

Groq-hosted models by default, which have a free tier. If you add an Anthropic key, Claude writes them instead. Whisper turns your speech into text.

Why a code instead of "Sign in with Google" on the glasses?

Google blocks its sign-in inside embedded web views like the one the glasses app runs in. You finish signing in on a normal web page with the code the glasses show.

Why are my Promotions and Spam emails missing?

On purpose. Glance only looks at unread mail in your Primary tab, because marketing mail does not need a reply.

Can I use it in another language?

Speech recognition is set to English for now.

What does it cost to run?

It is built to run on free tiers: Groq's free plan and Google's test mode. No paid service is required.
